# 未来实验协议建议

此文是实验设计建议，当前目录没有统一标注、统一划分、训练结果或验证完毕的benchmark。按以下步骤完成数据审计后，才适合开展跨场景实验。

## 原始标签与候选映射

| 来源原标签示例 | 候选分析组 | 必须保留的区别 |
|---|---|---|
| void、cavity、Vd/Vs/Cd/Cs | 空隙相关异常 | 几何、所在层、含水状态及作者void/cavity定义 |
| delamination、SDNET Class2/3、D | 层间／层内分离 | 相对钢筋层的位置、真值获得方式 |
| debonding | 界面脱粘 | 界面材料、接触状态；不与脱层物理等同 |
| looseness、crack、corrosion | 其他异常 | 不直接改为空洞；多缺陷共存需保留 |
| rebar、pipeline、intact | 特定目标／正常候选 | 不能仅因没有空洞标注就当确认正常；需排除未知异常 |

映射另存独立版本文件，保留source_label、mapped_label、mapping_reason、uncertainty。二分类“异常”只是一种分析设定，必须同时报告原始类别指标，不掩盖物理差异。跨库真值定义不同应分组报告。

## A-scan节点和双关系

每个节点需唯一定位到dataset/site/structure/line/batch/trace，并保留原始波形、时间轴、道间距或坐标、增益及处理历史。空间邻近关系来自物理坐标或可靠道序；响应相似关系来自同一组节点的表征。检查两套边的节点ID与顺序完全一致，缺测道、变速采集与弯曲测线不能按图片列号假定等距。

仅有渲染图片一般不能恢复原始幅值、相位及完整采样信息；缩放、色彩映射和归一化还会改变响应。处理后的MAT、中心两道平均TXT和有限频带频域系数分别标记，不作为等价的未处理时域A-scan。MERL-GPR频率域数据如需时域变换，记录频率轴、相位和重建假设，并明确带宽限制。

拟合归一化、相似度阈值、近邻数及异常阈值只能用训练／验证部分；测试标签不得进入建图或参数选择。若做跨划分无标签连边的传导式评估，须单独声明，另给无跨测试连边的归纳式结果。

## 划分与重叠

优先按场地、结构、测线、采集批次划分；同一测线的相邻裁剪及全部增强版本属于同一组。模型随机种子、基础几何与扰动版本也需成组。不要随机拆分相邻图块再宣称跨场地泛化。

建立原始文件哈希、父图ID、裁剪坐标、测线与批次对照表，检查镜像、版本、近重复图及原始／派生重叠。MCG或TunGPR子集不能未经检查与其父来源分置训练和测试。无法核清交集时，将相关来源整体放在同一侧或排除跨库结论。

## 评价和许可

实测与仿真分别报告，混合数据拆分来源；仿真结果不能替代实测泛化证据。按场景、场地和原始类别报告召回率、精确率及异常检测指标；类不平衡时避免只报准确率。标签定位误差、深度范围、图像级／信号级单位须明确，模型间使用同一划分和同一单位，统计不确定性尽量以场地或测线为重采样单元。

公开下载不代表允许再分发。先核实每个来源及父来源许可，未经许可不上传统一数据包；优先发布获取清单、映射、划分ID与评估代码。保留原始数据版本与日期，报告缺失信息和排除原因。
