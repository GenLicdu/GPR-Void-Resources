# 分类、字段与计数规则

核验范围：2026-09-19至2026-09-20；参见[主目录](../README.md)。分类表达现有证据，后续发现新证据时应记录变更理由。

## 四个独立维度

| 维度 | 取值及依据 |
|---|---|
| 工程场景 | 隧道及地下衬砌、桥梁及桥面板、道路及路面、铁路及路基、机场道面、混凝土构件、地下空洞及岩土、管线周边、多场景、其他。按实际结构和采集场景分类，可多值。 |
| 相关性 | A：来源明确包含void、cavity、delamination、debonding等目标；B：其他结构缺陷或介质异常；C：一般目标／背景。仿真也可以为A。论文主题或潜在用途不足以确认发布数据含该标签。 |
| 来源属性 | 现场实测、实验室实测、数值仿真、混合、未披露。混合需说明具体组成，不默认含仿真。 |
| 开放状态 | 公开下载、注册后下载、申请访问、仅论文描述、链接失效、待核验。明确申请访问的资料留在候选文档，不计主目录公开独立数。 |

桥面板不能写成桥梁衬砌。管线探测不等于管线周边脱空；当前主目录管线标签主要表示一般管线目标。TIGPR的交通范围提及机场，尚未确认独立机场文件子集。普通介质分层、含水变化、裂隙或钢筋不能自动归A。B/C的预训练、负样本、迁移用途均为研究判断，并非已经验证的实验效果。

“公开下载”在本目录严格限定为一手页面提供公开文件入口；页面、文件列表、抽样下载另有字段。它不表示全部文件已成功传输。主目录14个独立来源中只有1个实际读取了小型数据样本；TunGPR归档列表仅部分核验。数字不能省略这个层级差异。

## 独立来源与派生关系

唯一ID不随名称或网址变更。一个数据来源的镜像、DOI、不同版本、转换代码、裁剪、增强与标注补包不另计。多场景在README只出现一次，计数从记录而非场景标签展开结果计算。

- SDNET2021及其转换代码、Zenodo软件存档归并；Mendeley地下设施与空洞数据和LCSkhalid代码归并。
- MCG GPR是派生图像汇编；完整记录的parent_dataset列出作者确认的四个父来源。父来源未逐个达到主目录标准，不能因此新增四个独立数。
- TunGPR两部分、537幅抽取图像与R标注补包合计一个来源；内部交集待核验，不将论文中的案例总数直接相加成独立样本数。
- 来源或重叠无法判断的条目留在候选。不同作者或仓库并不足以证明独立；当前“独立”依据一手发布和采集描述，尚未进行全库哈希或批次比对。

## 文件字段

CSV前四列依次是engineering_scenes、dataset_name、official_download_entry、scale_and_content_summary，对应README的“工程场景、数据集名称、官方下载入口、规模与内容摘要”。JSON键相同且顺序相同；多值列在CSV中序列化为JSON数组或对象，读取时需解析，不能按逗号手拆。

sample_counts逐项保存value、unit、scope。A-scan、信号、模型、B-scan、图片、裁剪／增强样本、测线、场地使用来源原单位，不混加。file_size与file_size_scope区别压缩包、模态子包、图件和单文件体积。没有精确采样间隔时不自行用窗口／点数推算。

parent_dataset记录已知父来源；overlap_relationship记录版本、镜像、子集与尚未验证的交集。independent_count_status控制统计，派生记录仍在表中但不加入独立数。evidence逐项保存日期、原始链接和证据摘要。稳定文件直链只有实际确认时才填写；没有直链的空数组表示未确认可用直链，不代表不存在文件。

“未披露”是已读来源没有提供；“未明确”用于没有明确许可；“待核验”是未查或证据不足；“未执行”表示未进行动作。未知不得以0替代。
