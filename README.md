# GPR-Void-Resources

GPR 脱空、空洞、脱层与脱粘研究资源目录，用于跨工程场景的数据选型、回波表示学习、多关系图学习和异常检测。这里只整理资源元数据、证据与使用限制，**不是已经统一标注、划分并验证完成的数据集或 benchmark**，不包含第三方原始数据，不训练模型。

联网核验日期：**2026-09-19 至 2026-09-20**；每条来源的实际日期保留在完整记录中。

## 数量与核验范围

- 主目录 **15 条记录**：**14 个独立来源**，另1个派生数据条目MCG GPR，不计独立数。
- 独立来源相关性：**A类 9、B类 1、C类 4**。辅助B/C共 5 个。
- 独立来源属性：现场实测 8、实验室实测 1、数值仿真 2、混合 2、未披露 1。GPR013混合现场与实验室；GPR014混合实验室与仿真。单一实测属性共 9 个。
- 独立来源开放状态：公开下载入口 **14**；注册后下载0、申请访问0、仅论文描述0、链接失效0、待核验0。含派生记录共 15 个公开入口。这里统计官方入口，**不等于全量文件已下载验证**。
- **1个独立来源完成小型数据样本读取核验**：GPR014的实验平均A-scan TXT；另读取IN和许可。其余未成功验证数据下载；GPR013曾尝试下载但完成未确认。GPR015仅部分文件列表核验，归档完整性待确认。
- 另有 **19 条候选／关联线索**，其中2条为主目录已计来源的代码存档交叉引用，实际待获取或待核验线索 17 条。详见[候选线索](docs/candidate_leads.md)，全部不增加独立数。
- 检索目标30–50个独立来源；距下限30 **差 16 个**；直接相关A类距30差 21 个。不足不代表公开资源总量不足，也不以一般GPR数据补齐。

## 分类与计数

A：来源明确含空洞、脱空、脱层或脱粘；B：其他结构缺陷或介质异常；C：一般目标／背景。来源属性与相关性独立。模型数、图片数、增强数、A-scan 数、测线与场地数分别统计。多场景只计一次；镜像、版本、代码、格式转换与增强不新增独立数。

下表按工程场景分组，每条主记录只展示一次。多场景标签表示作者描述范围，不代表各子场景都已验证到具体样本。铁路路基包含1个辅助B类实验／仿真来源；机场仅由 TIGPR 范围描述覆盖，未核验独立机场子集；管线标签不代表管周脱空。

完整的采样、幅值、位置、许可、证据及验证状态见 [CSV](data/dataset_catalog.csv) 和 [JSON](data/dataset_catalog.json)。JSON 为数组；CSV 多值列用 JSON 字符串保存，二者可无损对应。前四列依次为工程场景、名称、官方下载入口、规模摘要。

## 实验使用限制

仅有渲染图片时，通常无法恢复原始幅值、相位及完整采样信息；不能默认可进行原始 A-scan 建模。处理后的 MAT 数据和有限带宽频域波场也需单独评估。各行的“建模适用性”是基于当前证据的研究判断，不是已完成实验的结论。

保留 void、cavity、delamination、debonding、looseness 等原始标签，不直接将其视为物理等价。优先按场地、结构、测线或采集批次划分训练／验证／测试；相邻裁剪、增强图、原始和派生数据不能未经重叠检查分置两侧。仿真与实测分别评价。公开可见或有下载按钮不代表文件已下载，也不代表许可允许再分发。

“未披露”表示已读来源没有给出该信息；“待核验”表示尚未验证或证据矛盾；“未执行”专指未做该动作。记录不推算缺失的采样间隔、不从文件名猜样本量、不从模型型号猜频率、不把压缩包大小当作纯雷达数据量。关联论文可能仅验证链接出处而未读全文，详见逐条限制。
